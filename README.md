# MBA Capstone Project Resources

This repository is a working document set for the MBA Capstone / Dissertation module. It collects topic ideas, module guidance, research-methods material, ethics resources, and short Markdown summaries of the most important files.

## Start here

1. Read the root [summary.md](./summary.md).
2. Review [Ideas/proposed_topics.md](./Ideas/proposed_topics.md) for the 18 dissertation topic options.
3. Open the folder summaries inside each section before digging into the source documents.
4. Use the official module handbook and live university guidance for any final submission requirements.

## Repository layout

- [01_Pre_Residency/](./01_Pre_Residency/) — pre-residency guidance and supporting material
- [02_Key_Documents/](./02_Key_Documents/) — dissertation handbooks, ethics pack, and reference material
- [03_Preparation_Work/](./03_Preparation_Work/) — preparation slides and exercises
- [04_Monday/](./04_Monday/) to [09_Post_Residency/](./09_Post_Residency/) — session materials and study documents
- [Ideas/](./Ideas/) — topic brainstorming and proposal drafts
- [Capstone Project/](./Capstone%20Project/) — current module documents and process files

## Notes

- Many source files are PDFs or Word documents; the Markdown summaries capture the main takeaways.
- Several resources are dated and should be checked against the current handbook and supervisor guidance before use.
- Ethics approval must be obtained before collecting any participant data.
